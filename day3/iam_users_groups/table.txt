Concept

What it means

IAM user

An identity used by a person or application to access AWS.

IAM group

A collection of IAM users that can share permissions.

IAM policy

A JSON document defining allowed or denied actions on AWS resources.

Least privilege

Granting only the permissions necessary for a task.

Access denied

AWS prevents an operation when effective permissions do not authorize it.
